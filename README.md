# AWS DevOps Assignment

## Objective
Deploy a simple website on an AWS EC2 instance using Ubuntu and Nginx.

## AWS Services Used
- Amazon EC2
- Security Group

## Linux Commands Used
- sudo apt update
- sudo apt upgrade -y
- sudo apt install nginx -y
- sudo systemctl status nginx
- sudo systemctl restart nginx
- df -h
- free -h
- ps aux

## Steps Performed
1. Created an Ubuntu EC2 instance.
2. Configured Security Group with SSH and HTTP.
3. Connected to the instance using SSH.
4. Installed and started Nginx.
5. Hosted a simple HTML website.

## Learning
- Learned how to launch an EC2 instance.
- Learned basic Linux commands.
- Learned to host a website using Nginx.
